Rhino 3DM previews for QuickLook on Windows.

This is a **preview/beta release**, not a claim of complete Rhino compatibility.

Features:
- Offline, read-only `.3dm` previews.
- Original, clay, wireframe and automatic per-object colors.
- Layers/objects, visibility, isolation, standard views and uncapped section planes.
- Host-to-viewer chunked model transfer; the model is not uploaded.

Installation: select the attached `.qlplugin` while QuickLook is running, press Space, install, then fully restart QuickLook.

Important limitations: Breps/extrusions need saved display meshes; renderer-specific materials and external linked resources are not reproduced. The current UI is Simplified Chinese. Full Windows QuickLook integration, all architectures and production-size assemblies still need validation.
